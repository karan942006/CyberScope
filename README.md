# Project Title- Web & Port Vulnerability Scanner-CyberScope
Description: CyberScope is a web-based vulnerability scanner developed using Python Flask. It performs port scanning, security header analysis, SSL/TLS verification, risk scoring, and generates security grades for target websites or IP addresses.
Features: 
           Port Scanning
           Security Header Analysis
           SSL/TLS Audit
           Risk Score Calculation
           Security Grading (A–F)
           Dashboard Visualization
           PDF Report Export
Technologies Used:
           Python
           Flask
           HTML
           CSS
           Bootstrap
           JavaScript
           Chart.js
Tech Stack & Tools:
            Programming Language: Python     
            Backend Framework: Flask
            Frontend Technologies: HTML,CSS,Bootstrap,Javascript,Chart.js
            Libraries Used: socket,requests,ssl,datetime
            Development Tools: Visual Studio Code,Git,GitHub
            Testing Tools / Platforms: Nmap,ScanMe,BadSSL,PortQuizTestPHP Vulnerable Web App,DVWA                                            (Damn Vulnerable Web Application)
            Browser Used:Google Chrome
